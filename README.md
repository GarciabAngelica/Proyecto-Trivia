# Trivia sobre Terminal y WSL

¡Una trivia interactiva para poner a prueba tus conocimientos en la terminal!

## Requisitos previos

Antes de comenzar, asegúrate de tener instalado:

* [Node.js](https://nodejs.org/) (versión 14 o superior)
* [Git](https://git-scm.com/)

## ¿Cómo jugar?

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/TU_USUARIO/proyecto-trivia.git](https://github.com/TU_USUARIO/proyecto-trivia.git)

2. En tu terminal entra a la carpeta del proyecto:
cd Proyecto-Trivia

3. Ejecuta:
node trivia.js
